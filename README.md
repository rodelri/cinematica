# cinematica

Repositorio de prueba para sincronizar Google Apps Script con GitHub y trabajar con Codex.

## Objetivo de la prueba
- Tener un repositorio base en GitHub.
- Sincronizarlo con un proyecto de Google Apps Script.
- Probar cambios con Codex sobre el código del proyecto.

## Estructura inicial
- `appsscript.json`
- `Code.gs`
- `Index.html`
